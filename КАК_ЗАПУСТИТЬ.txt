ФЛИПОЛОГИЯ — прототип приложения для флиперов (v0.1)

Что внутри
  Расчёт   — калькулятор сделки: прибыль, доходность, налог, ипотека, стресс-тест, вердикт
  Смета    — смета ремонта по площади и уровню, цены можно править
  Сделки   — карточки сделок: этап, расходы, чек-лист проверки, факт после продажи
  Справка  — налоги при продаже, проверка объекта, подготовка к продаже

Посмотреть на компьютере
  Двойной клик по index.html (откроется в браузере).

Поставить на телефон
  Нужен адрес в интернете с https (например, GitHub Pages, как у radioglob.ru).
  Выложить все файлы этой папки. Потом на телефоне открыть адрес:
    iPhone (Safari): «Поделиться» → «На экран Домой»
    Android (Chrome): меню → «Установить приложение»
  После установки работает и без интернета.

Где хранятся данные
  Только в памяти браузера на конкретном телефоне. Резервная копия —
  раздел «Сделки» → «Скачать копию» / «Загрузить копию».

Обновление
  Поменяли файлы — увеличьте номер версии в sw.js (flipologia-v1 → v2).

Файлы
  index.html            — всё приложение
  manifest.webmanifest  — название и иконка для установки
  sw.js                 — работа без интернета
  icon-192.png, icon-512.png — иконки
